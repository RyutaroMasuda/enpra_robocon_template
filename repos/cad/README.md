## ファイル構成

| パス | 中身 |
|---|---|
| `assembly/` | 全体アセンブリ・ユニットごとのサブアセンブリ |
| `parts/drive/` | 足回りの自作部品 |
| `parts/upper/` | 上物の自作部品 |
| `parts/frame/` | フレームの自作部品 |
| `purchased/` | 市販品（ネジ・ナット・ベアリング・モータ・サーボなど）のモデル |
| `export/stl/` | 3Dプリント用 |
| `export/step/` | 他CADとの受け渡し用 |
| `export/dxf/` | レーザーカット・板加工用 |
| `drawings/` | 図面 |
| `images/` | README用のスクショ |

> ユニット（`drive`, `upper`, `frame`）の分け方は自分たちの機体に合わせて変えてよい。
