# experiments

動作確認・お試し用のコード置き場。**実験のたびにリポジトリを作らず、ここに1フォルダずつ追加する。**

## ルール
- フォルダ名：`YYYYMMDD_<内容>_<名前>`
- 各フォルダに `README.md` を置き、下のテンプレを埋める
- うまくいったものは `firmware` に取り込む（コピーではなく、整理して移す）
- 失敗した実験も消さない。「なぜダメだったか」が後輩の財産になる
